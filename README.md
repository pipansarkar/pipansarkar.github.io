# pipansarkar.github.io

Hosts share links for the **AI Prompt** app (`/p/<prompt-id>`), the Android App Links file
(`/.well-known/assetlinks.json`) and a small landing page.

When you publish on Google Play, add the **App signing key SHA-256** from
Play Console → Setup → App signing to `sha256_cert_fingerprints` in `.well-known/assetlinks.json`.
